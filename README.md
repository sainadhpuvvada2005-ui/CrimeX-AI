# CrimeX AI

An AI-powered crime analysis and prediction platform built using:

- Next.js 15
- React 19
- FastAPI
- Python 3.11
- SQLAlchemy
- Zoho Catalyst
- Docker
- Tailwind CSS

## Features

- Crime prediction
- AI-powered analytics
- Interactive dashboards
- Reports
- Authentication
- Catalyst integration
- REST APIs

## Tech Stack

Frontend:
- Next.js
- React
- Tailwind CSS

Backend:
- FastAPI
- SQLAlchemy
- Python 3.11

Deployment:
- Zoho Catalyst AppSail
- Docker
