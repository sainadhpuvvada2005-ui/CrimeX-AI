# CrimeX AI Frontend

Modern Next.js interface for CrimeX AI.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Shadcn-style local UI components
- Framer Motion
- Lucide icons
- Dark mode via `next-themes`

## Pages

- `/login`
- `/dashboard`
- `/analytics`
- `/chatbot`
- `/gis-map`
- `/criminal-network`
- `/case-details`
- `/reports`
- `/admin`
- `/settings`

## Run

```bash
cd frontend
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

## Notes

The UI is ready to connect to the FastAPI backend under `backend/`. Current screen data is representative so the application is immediately navigable while API integration is completed.
